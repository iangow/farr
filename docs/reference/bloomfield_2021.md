# Firm-years in RDD analysis of Bloomfield (2021)

Firm-years in RDD analysis of Bloomfield (2021).

## Usage

``` r
bloomfield_2021
```

## Format

A tibble with 1,855 rows and 2 variables:

- fyear:

  Fiscal year

- permco:

  CRSP firm identifier (PERMCO)
