# Australian bank fundamental data

A data set containing fundamental financial information for Australian
banks.

## Usage

``` r
aus_bank_funds
```

## Format

A tibble with 283 rows and 7 variables:

- gvkey:

  GVKEY (firm identifier)

- datadate:

  Fiscal year-end

- at:

  Total assets

- ib:

  Income before extraordinary items

- xi:

  Extraordinary items

- do:

  Income from discontinued operations
