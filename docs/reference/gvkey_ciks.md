# GVKEY-CIK links

Link table from GVKEYs to CIKs

## Usage

``` r
gvkey_ciks
```

## Format

A tibble with 49,089 rows and 5 variables:

- gvkey:

  GVKEY (Compustat firm identifier)

- iid:

  Issue ID

- cik:

  CIK (SEC firm identifier)

- first_date:

  First link date

- last_date:

  Last link date
