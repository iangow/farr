# Event windows from Zhang (2007)

A data set containing the event windows used in Zhang (2007). Data
obtained from Panel of Table of Zhang (2007).

## Usage

``` r
zhang_2007_windows
```

## Format

A tibble with 17 rows × 3 variables.

- event:

  Identifier for the event

- beg_date:

  First date of event window

- end_date:

  Last date of event window
