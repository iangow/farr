# Firm-years for replication of Fang, Huang and Karpoff (2016)

A data set containing the GVKEYs and datadates for firm-years used in
Fang, Huang and Karpoff (2016).

## Usage

``` r
fhk_firm_years
```

## Format

A tibble with 60,272 rows × 2 variables.

- gvkey:

  GVKEY (firm identifier)

- datadate:

  Fiscal year-end
