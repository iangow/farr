# Russell 3000 stocks at time of SEC Reg SHO sample formation

A data set containing the tickers and company names for Russell 3000 at
time SEC created the pilot sample. Data are created from sample supplied
by FHK.

## Usage

``` r
sho_r3000
```

## Format

A tibble with 3000 rows × 2 variables.

- russell_ticker:

  Ticker

- russell_name:

  Company name
