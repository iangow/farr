# Event dates from Zhang (2007)

A data set containing the event dates used in Zhang (2007). Data
obtained from Panel of Table of Zhang (2007). If an event spans multiple
dates, then a row is included for each date.

## Usage

``` r
zhang_2007_events
```

## Format

A tibble with 30 rows × 3 variables.

- event:

  Identifier for the event

- date:

  Date of event

- event_desc:

  Description of the event

## Source

[doi:10.1016/j.jacceco.2007.02.002](https://doi.org/10.1016/j.jacceco.2007.02.002)
