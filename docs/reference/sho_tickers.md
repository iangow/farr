# Tickers of pilot firms for Reg SHO

A data set containing the tickers and company names for pilot firms from
Reg SHO pilot. Data are scraped from the SEC's own website.

## Usage

``` r
sho_tickers
```

## Format

A tibble with 986 rows × 2 variables.

- ticker:

  Ticker

- co_name:

  Company name

## Source

<https://www.sec.gov/rule-release/34-50104>
