# AAERs from Bao et al. (2020)

A data set containing AAER firms-years used in Bao et al. (2020).

## Usage

``` r
aaer_firm_year
```

## Format

A tibble with 415 rows and 4 variables:

- p_aaer:

  AAER identifier

- gkvey:

  GVKEY (firm identifier)

- min_year:

  First affected year

- max_year:

  Last affected year
